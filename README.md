Super Mario 3D Land Mod Manager

A Nintendo 3DS homebrew application project for managing compatible mods for Super Mario 3D Land.

Planned Features

- Browse a catalog of compatible mods.
- View mod descriptions and version information.
- Download supported mods.
- Install and uninstall mods.
- Manage installed mods.
- Check for mod updates.
- Back up and restore managed files.
- Provide a Nintendo 3DS dual-screen interface.

Development

This project is being developed using C++ and the Nintendo 3DS homebrew development tools.

The project is designed to support development and remote builds through GitHub Actions.

Important

This project is independent and is not affiliated with Nintendo.

Mod compatibility and installation methods must be verified before use. Original game files are not included.
